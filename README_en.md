# Tern

> Distributed Playwright Test Execution Platform

Tern is a lightweight, distributed platform designed for running Playwright end-to-end tests across multiple workers.

## Monorepo Layout

- `packages/`: Core libraries and shared utilities
- `apps/`: Application services (orchestrator, worker agent, dashboard)

## Getting Started

```bash
pnpm install
pnpm build
```
